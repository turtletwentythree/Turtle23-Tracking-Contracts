# ลิงก์เปิดไฟล์แนบจากระบบ Production โดยตรง

ไฟล์แนบเก่าบางไฟล์ (ประมาณ 310 ไฟล์) ระบบ Production เก็บไว้แค่ลิงก์ "โฟลเดอร์ของสัญญา" ใน Google Drive ไม่มีลิงก์ของตัวไฟล์
เว็บจึงแสดงเป็น 📁 ชื่อไฟล์ (โฟลเดอร์) และกดแล้วเปิดโฟลเดอร์ ขั้นตอนนี้หาไฟล์ในโฟลเดอร์ตามชื่อ แล้วเก็บลิงก์ของไฟล์ไว้ในตาราง attachment_links
หลังจากนั้นกดชื่อไฟล์จะเปิดไฟล์ทันที (📎) ทำครั้งเดียว ถ้ามีไฟล์เก่าเพิ่มภายหลังทำซ้ำได้

0. รัน `migrations/018_attachment_links.sql` ใน SQL Editor (ครั้งเดียว)
1. SQL Editor: รัน `1-export.sql` แล้วคัดลอกค่าในช่อง items ทั้งหมด (อ่านอย่างเดียว ไม่แก้ข้อมูล)
2. script.google.com > New project: วางโค้ด `2-find-files.gs` แล้ววางค่าจากข้อ 1 แทน PASTE_STEP_1_JSON_HERE กด Run (findFiles)
   ใช้บัญชี Google ที่เปิดโฟลเดอร์ของระบบ Production ได้ สคริปต์อ่าน Drive อย่างเดียว และสร้าง Google Doc ที่มี SQL ของข้อ 3 (ลิงก์อยู่ใน Execution log)
3. คัดลอก SQL ทั้งหมดใน Google Doc ไปวางใน SQL Editor แล้ว Run

ไฟล์ที่หาไม่เจอจะอยู่ท้าย Google Doc และยังเปิดโฟลเดอร์เหมือนเดิม
